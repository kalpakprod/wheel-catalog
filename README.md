# wheel-catalog

Каталог проектов для плагина [wheel](https://github.com/kalpakprod/wheel): на шаге `S3`
плагин ищет здесь готовое решение задачи пользователя, прежде чем писать код.

Данные лежат в релизах, а не в дереве репозитория: файл перезаписывается целиком каждые
сутки, и коммитить его означало бы заставить каждого, кто ставит плагин, качать историю
этих перезаписей.

## Что в релизе

| Файл | Что внутри |
|---|---|
| `catalog.jsonl.gz` | по строке JSON на проект |
| `manifest.json` | `version`, `built_at`, `count`, `sha256`, `bytes`, `schema_v`, `mirrors` |

Поля карточки: `slug`, `url`, `summary`, `problem`, `audience`, `alt`, `keywords`, `stack`,
`deploy`, `selfhost`, `mode`, `gap_ops`, `risks`, `level`, `deploy_gap`, `stars`,
`pushed_at`, `lang`, `license`, `mentions`, `chats`, `reactions`.

`problem` — задача словами ищущего, `alt` — чем проект заменяют, `keywords` — термины ниши
на русском и английском. По этим трём полям плагин и ищет. `chats` считает, в скольких
**разных** сообществах о проекте говорили: два независимых упоминания весят больше тысячи
звёзд, потому что звёзды копятся годами, а разговор идёт про то, чем пользуются сейчас.

Оценок вида «стоит ли это ставить» здесь нет намеренно: они зависят от того, что уже есть
в стеке у конкретного человека, и в общем каталоге вводили бы в заблуждение.

## Как это получить

Плагин обновляет каталог сам, фоном, не чаще раза в сутки. Руками:

    curl -fsSL https://github.com/kalpakprod/wheel-catalog/releases/latest/download/catalog.jsonl.gz \
      | gzip -dc > ~/.claude/wheel/catalog.jsonl

Зеркала перечислены в `manifest.json`. Целостность проверяется по `sha256` оттуда,
поэтому зеркало может быть любым.

Отключить автообновление: `WHEEL_NO_UPDATE=1` или `{"autoupdate": false}`
в `~/.claude/wheel/config.json`.

## Откуда данные

Сборщик читает открытые телеграм-каналы и чаты про инструменты разработки, достаёт ссылки
на проекты, добирает метаданные с GitHub, считает зрелость и прогоняет карточку через
модель. Тексты сообщений в каталог не попадают — только счётчики упоминаний.
